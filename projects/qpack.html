qpack

Scan exam pages, read the Arabic physics, grade the answers.

PythonAGPL-3.0★ 1betaCLI & tools
View the source Documentation

qpack is a command-line study tool for students and teachers. It takes photos of exams and homework workbooks, deskews the pages, runs OCR through the Gemini Vision API, evaluates multiple-choice answers, groups questions by physical concept and formula, and packages everything into portable .qpack archives.

With no API key or while offline it falls back to a built-in fixture instead of failing, so the whole pipeline stays testable.

What it does

  • Vision OCR

    Talks to Google Gemini through plain requests — no heavy SDK to install.

  • Watermark-resistant deskewing

    Estimates page tilt from horizontal edge projection variance, straightens rotated captures and filters out background teacher watermarks.

  • First-class Arabic

    Full bidirectional Unicode support, Arabic-Indic numeral normalisation (٠١٢٣ ↔ 0123) and standard multiple-choice letter normalisation.

  • Maths as LaTeX

    Physics equations are parsed and rendered as standard LaTeX.

  • Pencil working and review flags

    Crops both the printed question and the handwritten margin, scores OCR confidence, and flags faint handwriting below 70% for manual review.

  • Concept and formula grouping

    Organises questions by physical concept (e.g. عزم الازدواج المغناطيسي) or by underlying formula (e.g. τ = B I A N sinθ), not only by number.

  • Portable bundles

    A .qpack is a plain ZIP: manifest.json, questions.json and the cropped images.

  • Tested

    Unit tests for Arabic handling, deskewing, packing, grading and the CLI.

Install

  1. 1

    Prerequisites in Termux

    pkg install -y python python-pillow python-numpy
  2. 2

    Install qpack

    cd ~/qpack
pip install -e .
  3. 3

    Set the API key

    export GEMINI_API_KEY="your-google-gemini-api-key"

How to use it

Scan a page into an archive

qpack scan page1.jpg -o page1.qpack

Check answers and flag weak reads

qpack check page1.qpack

Inspect questions and solutions

qpack show page1.qpack --group-by concept   # default
qpack show page1.qpack --group-by formula
qpack show page1.qpack --group-by number

What check prints

Question number, concept, your choice, the verified correct choice, status (✓ RIGHT / ✗ WRONG / - SKIPPED), OCR confidence for the margin working, and a review flag for low-confidence reads.

Good to know

  • Phase 1. The Gemini call is optional, and the offline fixture is a real chapter 2 workbook, not random data.
  • Scanning sends page images to Google's API when a key is set — that is the only network step.
  • Bundles are ordinary zips, so you can inspect or edit them with any zip tool.
