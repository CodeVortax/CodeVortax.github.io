twrp-theme-studio

Visual, live-preview editor for TWRP recovery themes.

JavaScriptAGPL-3.0★ 0appWeb
View the source Documentation

It loads a real TWRP theme — ui.xml, portrait.xml and the images — renders it with a proper theme engine that understands templates, styles, conditions, lists, keyboards and sliders, and lets you edit the theme by tapping the elements in a live preview.

Variable edits patch only the changed line, so the git diff stays small and reviewable.

What it does

  • Preview mode

    Tap buttons to navigate like the real recovery, pick any page from the dropdown, and use ← to go back.

  • Select mode

    Tap any element to inspect it, drag to move, and nudge with the arrow keys (Shift moves 8px). Edit position, anchor, text, colours, font, image and style, or delete elements.

  • Colours

    Every theme colour with alpha, plus the hard-coded ones (keyboard, navbar) grouped for replace-everywhere.

  • Layout

    Font sizes and every numeric variable — header height, indent, list heights — driven by sliders.

  • Images

    Tap or drop to replace, auto-resized to the original size, with tint and reset.

  • Presets

    Dracula, Nord, AMOLED, Catppuccin and more, or a random palette; image buttons and icons are recoloured to match.

  • Simulate

    Battery level, clock, Samsung navbar, keyboard, busy state and font scale, all preview-only.

  • History and saving

    Undo and redo, Save with optional git commit and push, and Export ui.zip which does not touch the source.

  • Shortcuts

    Ctrl+S saves, Ctrl+Z / Ctrl+Y undo and redo, Esc deselects.

Install

  1. 1

    Run it

    npm install          # only needs express
npm start            # http://localhost:8080
  2. 2

    Edit the real recovery source

    THEME_DIR=/path/to/android_bootable_recovery/gui/theme npm start
  3. 3

    Environment

    PORT, HOST, THEME_DIR and DENSITY (default portrait_hdpi).

How to use it

A normal session

Start in Preview mode to find the screen you want, switch to Select mode, tap the element, change its properties in the sidebar, then Save or Export ui.zip. Try a preset first if you only want a new colour scheme.

Good to know

  • Fonts are not in the repo, so the preview uses Roboto Condensed look-alikes. Use Simulate → Font scale if sizes feel off.
  • Edits to elements, styles and fonts rewrite the XML tab-indented: comments are kept, blank lines are dropped.
  • The bundled theme is a copy; point THEME_DIR at your own recovery source to edit the real one.
