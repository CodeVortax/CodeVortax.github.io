esp-usb-bridge

Flash and monitor an ESP32 from Termux. No root, no PC.

JavaMIT★ 2appAndroid
View the source Documentation

Android does not let Termux open USB devices, and without root there is no /dev/ttyUSB0. This app fixes that from the other side: it is allowed to use the USB port, so it does, and it serves that port to Termux on 127.0.0.1:2217 using RFC 2217 — a standard esptool and pySerial already understand.

Automatic reset into the bootloader, baud-rate changes and the serial monitor all work, so flashing from a phone feels like flashing from a PC.

What it does

  • Real flashing

    esptool over the bridge, with automatic bootloader reset on DTR/RTS and speeds up to 921600.

  • The espb command

    start, status, flash, erase, info, mac, monitor, log and doctor.

  • Starts itself

    espb flash opens the app and starts the bridge if it is not running yet.

  • Scriptable logs

    espb log --seconds 20 --out boot.log --reset prints timestamped lines and exits.

  • Many chips

    CP210x, CH340/CH34x, FTDI, PL2303 and the ESP32's built-in USB, through usb-serial-for-android.

  • Local only

    The port listens on 127.0.0.1, so nothing else on your network can reach the board.

  • Tested protocol

    CI runs the protocol against a real pySerial RFC 2217 client on every push.

Install

  1. 1

    The app

    Take esp-usb-bridge-debug.apk from the latest release or Actions run and install it. Android will ask you to allow installs from this source.

  2. 2

    Termux

    curl -fsSL https://raw.githubusercontent.com/CodeVortax/esp-usb-bridge/main/termux/install.sh | bash
  3. 3

    The board

    Plug it in with a data USB cable and an OTG adapter. Tap OK on the USB permission prompt, ideally Always.

How to use it

Everyday commands

espb start                       # open the app and start the bridge
espb status                      # running? which device? client connected?
espb flash firmware.bin          # write firmware at 0x0
espb monitor                     # serial monitor
espb log --seconds 20 --reset    # capture boot log and exit
espb doctor                      # check the Termux side

Good to know

  • Wrong boot mode detected (0x13): the board did not enter download mode. Hold BOOT while it says Connecting..., or pass --manual.
  • The bridge did not come up: plug the board in first, then run espb start and tap OK within 45 seconds.
  • If it stops with the screen off, turn off battery optimisation for the app.
  • Only one client at a time — close espb monitor before flashing.
  • An architecture diagram and flashing notes are in docs/.
