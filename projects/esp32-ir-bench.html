esp32-ir-bench

Build virtual remotes. Capture codes from your old clicker. Fire them back from your phone.

C / HTMLAGPL-3.0★ 1betaESP32
View the source Documentation

An ESP32 that learns infrared codes from a real remote and replays them through an IR LED, with a phone-friendly web app served by the chip itself. No cloud, no app store install: join the WiFi and open the board's IP.

Remotes survive reboots because names, layouts and codes are stored in flash. Button photos stay in your phone's browser, because they are too big for the chip.

What it does

  • Two ways to build a remote

    Add circle, square, pill or bar buttons one by one, or photograph your real remote and tap where each button is.

  • Learn mode

    Hold a button, press the same key on the old remote, and the ESP32 decodes protocol, bits and code.

  • Run mode

    Tap a button to send the code out of the IR LED. Photo remotes show invisible hotspots over the real picture.

  • Persistent remotes

    Names, layouts and codes live in flash (LittleFS), so a power cut does not lose your remotes.

  • No app, no cloud

    The whole UI is served by the chip and works over its own hotspot if there is no router.

  • WiFi from your phone

    No password baked into the code — you enter the network from the setup page.

Install

  1. 1

    Build one flashable file

    pip install -U platformio
./build.sh merge          # -> dist/esp32dev-merged.bin
  2. 2

    Can't build on a phone?

    Push to GitHub and download the firmware artifact from Actions instead.

  3. 3

    Flash it at offset 0x0

    See the flashing guide in docs/guides/flashing.md.

  4. 4

    Set up WiFi from your phone

    The board opens a hotspot named IR-Bench (password irbench123). Join it, open http://192.168.4.1/setup, pick your network, enter the password and tap Save and restart. Afterwards find its IP on the serial monitor at 115200 or in your router's device list.

  5. 5

    Change networks later

    Open /setup again, or hold BOOT for 5 seconds to forget the saved WiFi.

How to use it

Using the bench

Open the board's IP, create a remote, then switch a button into learn mode and press the matching key on the old remote. Once learned, tapping the button fires the code.

Good to know

  • Power the receiver from 3V3, never VIN — VIN is 5 V and would put 5 V on the signal pin.
  • Receiver pinouts differ. With the dark window facing you and the legs down, most read VCC, GND, OUT or OUT, GND, VCC from left to right.
  • Change the GPIO numbers in include/config.h.
  • A bare LED works for bench testing because bursts are milliseconds long, but add a 100 to 150 ohm resistor as soon as you have one.
