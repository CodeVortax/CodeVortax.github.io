relink

A downloader for the sites that don't give you a real file link.

PythonAGPL-3.0★ 2betaCLI & tools
View the source Documentation

Download a movie or an episode from a site and you often get a temporary link that expires after a few minutes. If the connection drops halfway, the link is dead and the download is lost — painful on mobile data.

relink's answer: a download should never be tied to one link. It remembers the page and how to get the link from it, so when the link expires or the connection drops it fetches a fresh link and continues from the same byte.

What it does

  • Survives bad connections

    Retry, refresh the link, resume. No manual restarts.

  • Continuous link refresh

    Expired or tokenized links are replaced automatically, mid-download.

  • Template mode

    Small YAML step lists (get, post, form, find, choose) that describe how a site goes from page to direct file link.

  • Generic mode

    If no template matches, the URL goes to yt-dlp with settings tuned for bad connections.

  • Easy to extend

    Adding a site means writing a small template file, not new code.

  • Remembers jobs

    Job state is saved per job, so relink resume continues after a reboot.

  • Discovery tools

    A small search API for episodes, a server lister, and relink discover to fingerprint and group new sites.

Install

    Install in Termux

    pkg install -y python git
git clone https://github.com/CodeVortax/relink
cd relink
pip install -e .          # installs pyyaml and the `relink` command
  2. 2

    Optional generic mode

    pip install yt-dlp && pkg install -y ffmpeg

How to use it

Downloading

relink search the mentalist               # small search API (episodes)
relink servers <episode-url>              # servers on a page and which have an adapter
relink get <episode-url>                  # best quality, saved to ~/storage/downloads/relink
relink get <url> --quality low --out ~/storage/downloads
relink get <url> --dry                    # only print the direct link
relink list                               # jobs and progress
relink resume                             # continue unfinished jobs

Behind a Cloudflare challenge

relink get <url> --cookie "cf_clearance=..."

Forcing yt-dlp

relink get https://www.youtube.com/watch?v=...   # no template: uses yt-dlp
relink get <url> --ytdlp                         # force it even if a template matches

How a template works

A template says how to get from a page to a direct file link: read the page's server list, open the download host, pick a quality, submit the form. The engine is in relink/engine.py.

Good to know

  • Only download content you have the right to download, and respect each site's terms.
  • Templates need only Python and PyYAML; yt-dlp is optional.
  • Sites change, so a template can break. relink servers tells you which hosts still have an adapter.
  • Open work: adapters for more hosts, series mode, and a site analyzer that drafts a template from a fingerprint bundle.
