esp32-wifi-repeater-manage

Share your WiFi on purpose. See it. Limit it.

CAGPL-3.0★ 1betaESP32
View the source Documentation

A repeater built on one idea: whoever uses your internet should be visible, and capped. The ESP32 joins your router as a client and opens its own network next to it. Phones and laptops connect to the ESP32 and their traffic is forwarded to the router through NAT.

Because every byte passes through the chip, it can count usage per device, cut a device off when it hits its daily quota, show the domains being looked up, and report to you over Telegram. Everything runs on the chip: no cloud, no account, no app.

What it does

  • AP + STA with NAT

    NAT turns on as soon as the router gives an address, and again after every reconnect.

  • Background connect

    Startup never waits for the router, so the dashboard is reachable immediately.

  • DNS through the ESP32

    DHCP hands out the ESP32 as the DNS server, so every lookup is seen and then forwarded upstream.

  • Per-device counting

    Counted at the network-stack level, in both directions, per device MAC.

  • Daily quota

    Default 1 GB per device per day, changeable per device, or 0 for unlimited.

  • Block and whitelist

    A blocked device stays connected but gets no traffic; whitelisted devices are never limited.

  • Local midnight reset

    Time-zone and daylight-saving aware (Egypt by default), and correct even when the board reboots across midnight.

  • Remembers devices

    Limits, whitelist, blocks and counters are kept in flash, written every minute and only when something changed.

  • Router-style dashboard

    Login screen, then Overview, Users, Apps, Speed, Settings and System. Arabic and English, full right-to-left.

  • Per-app usage

    Named users with usage per category and per app (YouTube, TikTok, Facebook, WhatsApp, Telegram, Google, Snapchat), with new domains teachable from the dashboard.

  • Blocking and filtering

    Built-in 18 KB ad / tracker / site list plus your own hosts file, a choice of filtering DNS (Cloudflare Family, AdGuard), and an Internet off switch.

  • Speed limits

    For the whole network, a default per user, and per user.

  • Update over WiFi

    Send ota-firmware.bin or ota-ui.bin from System > Update. A bad firmware rolls back by itself.

  • Telegram bot

    Status, block, unblock, whitelist, quota and ping, restricted to the chat ID you saved.

Install

  1. 1

    Get the firmware

    Take the firmware artifact from the latest Actions run, or a file from Releases. It is one file that already contains the web UI.

  2. 2

    Or build it yourself

    git clone https://github.com/CodeVortax/esp32-wifi-repeater-manage
cd esp32-wifi-repeater-manage
pip install -U platformio
./build.sh merge        # -> dist/esp32dev-merged.bin
  3. 3

    On Termux

    ./build.sh bin also copies the firmware to your Downloads folder.

  4. 4

    Flash it at offset 0x0

    esptool.py --chip esp32 --port /dev/ttyUSB0 write_flash 0x0 esp32-wifi-repeater.bin
  5. 5

    Or flash from Chrome

    ESP Web Tools works from the browser, which is handy when you only have a phone.

  6. 6

    First run

    Join the WiFi AOSP (password 12345678) and open http://192.168.4.1. Log in as admin / admin1234, then in Settings enter your home WiFi, a new repeater password and a new dashboard password. The ESP32 reboots and joins your router.

How to use it

Running it

Open the dashboard at the board's IP, or talk to the bot. Every change is validated before it is saved, and every state-changing call has cross-site protection.

Telegram commands

CommandDoes
/statusEvery device with usage and state
/block <mac> · /unblock <mac>Cut off or restore a device
/whitelist <mac> · /unwhitelist <mac>Exempt a device from the quota
/setquota <mac> <mb>Daily limit in MB, 0 means unlimited
/ping <host>Ping from the repeater

Good to know

  • Change the default dashboard password immediately — the page keeps warning you until you do.
  • The dashboard, the API and the live WebSocket all require a signed-in session, with lock-out after 5 wrong tries.
  • Hold BOOT for 5 seconds to wipe the saved settings if you lock yourself out.
  • A reboot across midnight still resets quotas correctly.
