rtlterm

Arabic, Persian, Urdu and Hebrew in terminals that can't join or reverse text.

PythonAGPL-3.0★ 2stableCLI & tools
View the source Documentation

A terminal draws one character per cell, left to right, in the order it receives them. Right-to-left text then shows up with separate letters and backwards words, and Arabic mixed with English or numbers gets scrambled.

rtlterm fixes that in the terminal you already have. It is pure Python, has no dependencies, and uses only the Unicode data that ships with Python.

What it does

  • Shapes letters

    Picks the initial, medial, final or isolated form so words look joined, including the lam-alef ligature (لا), Persian and Urdu letters, and harakat that do not break joining.

  • Reorders lines

    A practical subset of Unicode UAX #9: mixed Arabic / English / numbers, digits, punctuation and mirrored brackets.

  • Wraps, then reorders

    Long lines are wrapped by terminal cell width and each wrapped line is reordered on its own, so wrapping no longer scrambles the text.

  • Right alignment

    Optionally flushes right-to-left lines to the right margin.

  • Keeps colours

    ANSI colour codes stay on the right words after reversing.

  • Leaves LTR alone

    Lines with no right-to-left text pass through untouched, so progress bars and normal output are unaffected.

  • Idempotent

    Running it twice on the same Arabic text is safe.

  • Shows its work

    rtlterm --demo prints the same sentences four ways so you can pick the block that reads correctly in your terminal.

How to use it

As a filter

relink search the mentalist | rtlterm
cat arabic.txt | rtlterm
rtlterm file.txt --width 60 --align right

From Python

from rtlterm import fix, rprint

print(fix("مسلسل The Mentalist الموسم الثالث الحلقة 17"))
rprint("مرحبا بالعالم")   # print() that fixes right-to-left text first

Options

fix(text, width=None, base="smart", align="auto", marks="keep", digits=None, wrap=True)
base: smart follows the first word with letters, skipping ids and numbers, so b24fde4d0 مسلسل ... is right-to-left; auto follows the first letter; rtl / ltr force it.
align: auto, left, right or center.
marks: strip removes harakat, which many terminal fonts draw badly.
digits: arabic (٠١٢) or latin (012).

Good to know

  • The output is for display only. Do not save or search it — it uses presentation forms. Keep the original text and fix it at the moment you print.
  • If your terminal already handles Arabic correctly, you do not need this.
  • Needs a font with the Arabic presentation forms; Android's default has them.
  • Not implemented: explicit embeddings and isolates, and the bracket-pair rule N0.
  • Hebrew needs reordering only, since it does not need shaping.
