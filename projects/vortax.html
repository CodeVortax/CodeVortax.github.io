vortax

Run and manage QEMU virtual machines from one small CLI and a web dashboard.

PythonAGPL-3.0★ 2stableCLI & tools
View the source Documentation

Pick a system from the catalog, or bring your own ISO, disk image or archive. Vortax downloads it, prepares the disk, starts QEMU and gives you VNC access, optionally through a tunnel.

It is deliberately small: standard library only, so the .deb is a few hundred KB, and it runs on a phone in Termux as happily as on a VPS or a CI runner.

What it does

  • Standard library only

    No pip dependencies; the .deb is a few hundred KB.

  • KVM or software

    Uses KVM when you have it and software emulation when you don't — phones, most VPSes, CI runners.

  • Safe defaults

    VNC and the QEMU monitor are local-only, passwords are random per VM and never appear in process lists, tokens never go on a command line, and archives are extracted with path checks.

  • Testable

    The QEMU command is built by one pure function; vortax selftest --boot boots a generated 512-byte guest through the real pipeline to prove an install works.

  • Fresh catalog

    Entries like alpine, ubuntu-server, arch and tumbleweed look up the current ISO name when you run them, so they do not go stale.

  • Your own media

    A local ISO, a URL, or a .7z .zip .tar.* .gz .xz .bz2 .zst archive holding a disk image; the real disk format is detected.

  • Presets

    Save a set of options under a name and run it like a catalog id.

  • Sharing

    SSH forwarded to a random free local port, scp-style copy, and a 9p shared folder.

  • Devices

    USB passthrough and an emulated sound card.

  • Snapshots

    Stop saves the live state and the next start resumes it.

  • Utilities

    Screenshot to PNG, disk resize / info / compact, logs -f, and a background watcher that stops a VM after N minutes.

  • Phone aware

    On Termux RAM defaults are capped, doctor prints the pkg install line for missing tools, and a wake lock is taken while a VM runs.

Install

  1. 1

    Debian and Ubuntu, including proot on a phone

    curl -fsSL https://codevortax.github.io/vortax/install.sh | sudo sh
vortax doctor
  2. 2

    Anywhere with Python 3.9+

    pipx install .            # or: pip install .
pkg/apt install qemu     # you still need qemu-system-x86_64 and qemu-img
  3. 3

    Build the .deb

    MAINTAINER="You <you@example.com>" packaging/build-deb.sh   # -> dist/

How to use it

Quick start

vortax list                                   # the catalog
vortax plan --system ubuntu --boot-mode iso   # what would happen, and the exact QEMU command
vortax run  --system mint --tunnel bore       # prepare, start, wait; Ctrl-C stops cleanly
vortax start --system debian --name lab       # same, but returns immediately
vortax info --name lab --show-password        # address and VNC password
vortax stop --name lab
vortax start --name lab                       # restart: reuses how it was launched

More of it

vortax wizard                                   # questions, optionally saved as a preset
vortax preset save work --system ubuntu-server --ram-mb 4096 --ssh --share ~/code:code
vortax start lab --ssh && vortax ssh -u me      # SSH forwarded to 127.0.0.1
vortax cp ./notes.txt vm:/home/me/
vortax screenshot --name lab --out lab.png
vortax disk resize +20G --name lab
vortax logs -f --name lab

Drive it from the environment

VORTAX_SYSTEM=bazzite VORTAX_BOOT_MODE=iso VORTAX_RAM_MB=4096 vortax run
vortax config show     # the merged result, passwords redacted

Good to know

  • After an installer finishes, boot from the disk instead of the ISO: vortax start --name lab --boot disk.
  • Every option has a VORTAX_<NAME> variable, which is how scripts and CI drive it.
  • A wake lock needs termux-api; --notify uses termux-notification when it exists.
