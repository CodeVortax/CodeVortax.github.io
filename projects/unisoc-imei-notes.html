unisoc-imei-notes

Where a Unisoc phone keeps its IMEI, serial and MAC, and how the tools read them.

PythonAGPL-3.0★ 3research notesCLI & tools
View the source Documentation

Research notes on where a Unisoc (Spreadtrum) phone keeps its IMEI, serial number and MAC addresses, and how the common tools read or write them. The notes are built from the source of the Spreadtrum factory tool WriteIMEI R21, the C# NV editor SPRDNVEditor, the XDA thread on rooting an SP6820, and a read-only analysis of one real NV backup.

The repository also carries device-specific restoration tools for the Realme C21Y and the Realme C51, with a walkthrough of how they work.

What it does

  • Documented NV layout

    Where each identifier lives, which partitions hold it, and how the factory tools address it.

  • Tool analysis

    How WriteIMEI and SPRDNVEditor are built, and what their binaries actually do.

  • Read-only scanner

    Finds identifiers in a backup folder and can mask them in the output.

  • Restoration tools

    Complete, documented procedures for the Realme C21Y (RMX3261 / RMX3263) and the Realme C51 (RMX3830).

  • Honest scope

    Every inference is marked as an inference, and the limits of the analysis are written down rather than glossed over.

Install

  1. 1

    No install

    The tools are plain Python scripts with no dependencies. Clone the repo and run them where the backup is.

  2. 2

    Get it

    git clone https://github.com/CodeVortax/unisoc-imei-notes
cd unisoc-imei-notes

How to use it

Quick start

python3 tools/scan_backup.py /path/to/backup_folder
python3 tools/scan_backup.py /path/to/backup_folder --reported 123456789012345 --mask
python3 tools/scan_backup.py /path/to/backup_folder --serial YOURSERIAL
python3 tools/parse_miscdata.py /path/to/miscdata.bin --mask
python3 tools/idtool.py get /path/to/dump_folder --mask
python3 tools/idtool.py patch-imei /path/to/l_fixnv1_a.bin --imei1 YOURIMEI1 --imei2 YOURIMEI2 --out /path/to/l_fixnv1_a_patched.bin

Read the docs

The numbered docs in docs/ walk from the NV layout through each tool; HOW_IT_WORKS_C21Y.md and devices/c51/README.md cover the restoration tools.

Good to know

  • The scanner only reads. Nothing here writes identifiers to a phone.
  • WriteIMEI's real phone protocol lives inside a closed PhoneCommand.dll that is not in the source zip, so that part is described from the outside.
  • Legal: the IMEI identifies a handset to mobile networks. Restoring the number printed on your own device is a normal repair task; writing an IMEI that does not belong to the device is illegal in many countries and can get the phone blocked. These notes explain how the software is built — they are not a procedure for changing identifiers.
