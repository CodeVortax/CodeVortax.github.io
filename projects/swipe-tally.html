swipe-tally

Counts Shorts, Reels and TikTok swipes correctly.

KotlinMIT★ 2appAndroid
View the source Documentation

A small Android app that counts swipes in YouTube Shorts, Instagram Reels and TikTok — and does it correctly. It exists as a readable test bed for one problem: how do you count short-video swipes reliably with an AccessibilityService?

The obvious approach, counting TYPE_VIEW_SCROLLED events, gives wrong numbers. Android merges events that arrive close together, so several fast swipes become one. Small drags fire events even though the video snapped back. Comment sheets and carousels scroll too and fire the same events. One swipe fires a burst of events while the page animates, and a fixed "one count per 700 ms" rule throws away real fast swipes.

What it does

  • It counts video changes, not scroll events

    A swipe is counted only after the finger has stopped and the page has settled, and only if the video really changed.

  • Settle timer

    Every scroll event restarts a short timer (250 ms by default). When it fires the page has stopped moving and the whole burst is judged once.

  • Index mode

    A pager usually reports which page is showing (fromIndex == toIndex), which is a far better signal than scroll deltas.

  • Feed detection

    A fingerprint decides whether you are actually inside a short-form feed before any counting happens.

  • Floating pill

    Shows forward swipes, back swipes, today's total and which signal detected the feed.

  • Correction and tuning

    The main screen shows per-app counts for today and recent days with manual correction buttons, a reset, the settle time, and a flip-direction switch for apps that report scroll direction the other way round.

Install

  1. 1

    Build in Termux

    pkg install openjdk-17 gradle aapt2
# Android SDK platform 34 + build-tools must exist
# local.properties needs sdk.dir=/path/to/android-sdk
git clone https://github.com/CodeVortax/swipe-tally
cd swipe-tally
gradle assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk ~/storage/downloads/SwipeTally.apk
  2. 2

    Enable the service

    Install the APK, open the app, tap Open accessibility settings and enable Swipe Tally.

  3. 3

    If aapt2 fails

    Uncomment the aapt2 line in gradle.properties.

How to use it

Reuse it in your own app

You only need three pieces: the accessibility config, the settle runnable in SwipeService.kt, and Detector.fingerprint(). This is exactly the method Focus uses for its Shorts counter.

Good to know

  • MIT licensed: copy any part of it into your own project.
  • No internet permission, no dependencies and no analytics — everything stays on the phone.
  • App updates can change view ids; the detector may need adjusting for a new version of a feed app.
