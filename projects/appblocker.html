AppBlocker

Block, disable or whitelist apps from one local web UI.

ShellAGPL-3.0★ 0Magisk moduleAndroid
View the source

A Magisk module that removes or blocks apps on a Block list, disables apps on a Disable list and exempts anything on a Whitelist — with a small local web UI so you never have to edit files by hand.

After the first reboot, edits made through the UI or by hand take effect automatically within about 20 seconds. No reboot needed for routine changes.

What it does

  • Lists tab

    Block, Disable and Whitelist panels plus an "add a package" box.

  • Apps tab

    Browse every installed app, split into three risk tiers.

  • Hosts tab

    Network-wide domain blocking.

  • Logs tab

    Recently installed apps, a full activity log and a debug log.

  • Settings tab

    Lock mode, so the lists cannot be changed casually.

  • Launcher detection and app icons

    The UI shows real icons and knows which packages are launchers.

  • Block is sticky

    A blocked app is uninstalled for the current user and kept that way — reinstalling it gets it removed again automatically.

  • Disable is reversible

    A disabled app is turned off with pm disable-user: the icon disappears and the app cannot run, but nothing is deleted.

  • Whitelist wins

    An app on the whitelist is left alone even if it is still listed in blocklist.txt or disablelist.txt. The entries are not deleted, just ignored.

Install

  1. 1

    Install the module

    Copy AppBlocker.zip to the device, then Magisk app → Modules → Install from storage → select the zip.

  2. 2

    Reboot once

    This is only required the first time, to start the background service. After that the lists apply on their own.

  3. 3

    Open the UI

    On the phone: http://127.0.0.1:8765/cgi-bin/index.cgi. From another device on the same WiFi, use the phone's LAN IP instead of 127.0.0.1.

How to use it

Manual editing still works

# lists live in /data/adb/appblocker/
blocklist.txt
disablelist.txt
whitelist.txt

# what the module actually did
tail -f /data/adb/appblocker/appblocker.log

Pausing everything

Whitelist the apps you want left alone, or disable or remove the module in Magisk and reboot.

Good to know

  • Only target third-party apps or ones you have confirmed are safe to remove. Disabling core system packages (anything com.android.* or an unfamiliar OEM service) can cause boot loops.
  • When unsure, use Disable, not Block, and test one app at a time.
  • The activity log shows exactly what the module has done, so check it before blaming the module for a missing app.
